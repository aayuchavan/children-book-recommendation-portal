# StorySprout — Simple HTML/CSS/JS

Open `index.html` directly in Chrome or Edge.

Admin panel: `admin.html`
Username: `admin`
Password: `admin123`

Features:
- Book catalog
- Search/filter/sort
- Reading list
- Admin login
- Add/edit/delete books
- Recommendation weights
- Reset seed data

Data is stored in browser localStorage. No Node.js, npm, MongoDB or server is required.

## New ERP Admin Tab
The Admin Panel now includes an interactive ERP Dashboard with KPI cards, enterprise system status, publisher inventory, simulated workflow animation, and recent ERP events. All ERP data is demo/simulated data for presentation.
